About

This site tracks the AWS table of Bedrock model FedRAMP and DoD CSP SRG certification status: which models may run in U.S. East/West (FedRAMP Class C), U.S. GovCloud (FedRAMP Class D), and DoD (CSP SRG IL4/IL5) environments.

How it works

  • A scheduled check fetches the AWS page every morning (around 8:00 AM US/Eastern) and parses its embedded table deterministically — no AI involved, byte-identical input means no output.
  • If nothing changed, nothing is published. If a model gained availability in an environment, the site rebuilds, the per-environment inventory gains a first-seen date, and the feeds gain an item.
  • Removals are recorded in the history page but do not trigger a republish on their own; they ship with the next addition-triggered update.
  • Baseline is {{ fmt_med(baseline.date) if baseline else "—" }} ({{ source.source_last_updated }}): every model available then carries that first-seen date — except where an older archived snapshot of the page proves earlier availability (see below).

Backfill from archived snapshots

The AWS page was captured by the Internet Archive before the baseline (only two usable captures ever existed: May 11 and Jun 30, 2026). A one-time backfill moved the first-seen date earlier for every model-environment availability visible in those snapshots — exact name matches only, so reformatted rows conservatively keep the baseline date. No change events were fabricated; the backfill is recorded as a note in the history.

Machine-readable

models.json carries the full inventory, change log, and source metadata.
